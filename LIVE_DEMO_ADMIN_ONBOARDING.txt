CampGrids live demo: admin, teacher, and student accounts
==========================================================

Demo rule: every staff member uses the same simple account-activation path.
CampGrids emails a one-time invitation link. The recipient opens it and chooses
their own password. Do not create a temporary password, use the SQL editor, or
open admin-onboarding.html directly. That old URL is not part of this demo.

One-time production check
-------------------------

Run this only after changing the application or Supabase configuration. It is
already complete for the current production deployment, but these are the exact
commands to repeat if necessary.

1. Put the new Supabase personal access token in .env. Do not commit .env:

   SUPABASE_ACCESS_TOKEN=sbp_your_personal_access_token

2. From the repository root, deploy the database/configuration and website:

   $PROJECT_REF = 'hofninqlkcuzgboslodq'
   npm run setup:supabase -- --project $PROJECT_REF --origin https://camp-grids.vercel.app
   npx vercel --prod --yes --scope danishnadars-projects

3. Verify the staff invitation configuration before the audience arrives:

   npm run check:email-config -- --project $PROJECT_REF
   npm run verify:smtp

Create the demo administrator (before the presentation)
--------------------------------------------------------

Use a NEW, unused mailbox. Do not use danish@holacreo.com again: it already has a
CampGrids Auth account, and Supabase correctly refuses to invite an existing,
activated user. A dedicated demo mailbox is best. A Google Workspace plus-address,
such as danish+campgrids-admin-demo@holacreo.com, also works if plus-addressing is
enabled for that mailbox.

Run exactly one command:

   node scripts/provisionAdmin.mjs --email demo.admin@YOUR_APPROVED_DOMAIN --first-name Demo --last-name Administrator --department Tech --allowed-domains YOUR_APPROVED_DOMAIN

For a holacreo.com demo mailbox, the final argument is:

   --allowed-domains holacreo.com

Expected terminal result:

   Administrator invitation accepted by Supabase for <email>.

The command sends no password and prints no setup link. Supabase sends the branded
email through the configured Gmail SMTP account with subject:

   Your MSI staff account is ready

In the demo mailbox:

1. Open that email and choose "Set Up My Account."
2. Choose and confirm a private password (12+ characters).
3. Sign in at https://camp-grids.vercel.app/admin/ with the email and new password.
4. Enter the one-time verification code delivered to the same mailbox.
5. The Administrator workspace opens.

This is the administrator demo identity. Keep this browser window open for the
remaining setup.

Create the demo teacher (from the admin workspace)
---------------------------------------------------

1. In the Administrator workspace, open People.
2. Under "Add a teacher", enter a new demo teacher's first name, last name, and
   unused work email. Click "Create teacher account."
3. In the teacher mailbox, open "Your MSI staff account is ready," click "Set Up
   My Account," and choose a password.
4. In a separate incognito/private browser window, sign in at:

   https://camp-grids.vercel.app/auth.html

   Use the Teacher tab, enter the teacher's email (or assigned username) and new
   password, then enter the email verification code.
5. The Teacher workspace opens. Leave that window open for the presentation.

Create the demo student (from the admin workspace)
---------------------------------------------------

1. In the admin window, create a camp/class if one is not already available.
2. In the class roster import card, upload a one-row CSV using this exact header:

   first_name,last_name,grade,guardian_name,guardian_email
   Demo,Student,5,,

3. CampGrids displays the generated student username and the class code. Copy both
   into your presenter notes. No student email or password exists.
4. In another private browser window, use the student sign-in screen and enter the
   class code plus generated username.
5. The Student workspace opens. Keep this window open too.

Live presentation order
-----------------------

1. Administrator: show the People page and the active admin workspace.
2. Teacher: show the independent teacher window, class Grid, assignments, and
   camper progress tools.
3. Student: show the independent student window and the assigned class Grid.
4. Return to the admin window to show that the administrator can manage people,
   rosters, and the Mother Grid.

Fast recovery during the demo
-----------------------------

* Invitation missing: search the inbox and Spam/Junk for "Your MSI staff account
  is ready." On the admin People page, use "Resend invite" for a teacher. For an
  administrator, run the provision command with a new unused mailbox.
* Invitation link expired: resend it for a teacher. For an administrator, use a
  new demo email; never reuse a setup link.
* Staff sign-in code missing: wait one minute, then retry. Check Supabase Edge
  Functions -> request-staff-email-2fa -> Logs if the code still does not arrive.
* Do not navigate to https://camp-grids.vercel.app/admin-onboarding.html. It is a
  retired fallback page, not an invitation link.

Security and reliability notes
------------------------------

The one-time invitation link proves access to the recipient's mailbox and lets that
person choose the only password for the account. This is safer and simpler than
emailing credentials. Staff then complete the normal emailed verification code at
sign-in. Campers remain passwordless: their class code and generated username are
their demo credentials.
