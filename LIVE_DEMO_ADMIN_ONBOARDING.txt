CampGrids Demo: Exact Steps
===========================

Important
---------

Use a NEW email address for every new staff account. Do not use danish@holacreo.com
again because it is already a CampGrids account. Do not use set_admin.sql or open
admin-onboarding.html.

1. Create the demo administrator
---------------------------------

From the repository root in PowerShell, run this command. Replace ONLY
NEW_ADMIN_EMAIL with a new, unused email address.

  node scripts/provisionAdmin.mjs --email NEW_ADMIN_EMAIL --first-name Demo --last-name Admin --department Tech --allowed-domains holacreo.com

Example:

  node scripts/provisionAdmin.mjs --email danish+campgrids-admin-demo@holacreo.com --first-name Demo --last-name Admin --department Tech --allowed-domains holacreo.com

2. Activate the administrator account
--------------------------------------

1. Open the email with subject: Your MSI staff account is ready.
2. Click Set Up My Account.
3. Choose a password.
4. Go to https://camp-grids.vercel.app/admin/.
5. Sign in with the email address and password.
6. Enter the verification code sent by email.

If the email link first opens the regular CampGrids site, wait one moment. It now
automatically forwards to the password setup page. If it does not, open the same
link again in a private/incognito window.

3. Create the demo teacher
---------------------------

1. In the admin workspace, open People.
2. Complete Add a teacher with a new email address.
3. In the teacher's email, click Set Up My Account and choose a password.
4. In a private/incognito window, go to https://camp-grids.vercel.app/auth.html.
5. Select Teacher, sign in, and enter the emailed verification code.

4. Create the demo student
---------------------------

1. In the admin workspace, create or open a class.
2. Upload this CSV:

  first_name,last_name,grade,guardian_name,guardian_email
  Demo,Student,5,,

3. Copy the generated student username and class code.
4. In a separate private/incognito window, sign in as Student with the class code
   and username. Students do not use email or passwords.

5. If an email does not arrive
------------------------------

1. Check Spam/Junk for Your MSI staff account is ready.
2. For a teacher, use Resend invite in People.
3. For an administrator, run step 1 again with a different new email address.
